# ClearlyDue

Design-partner (pilot) page for ClearlyDue, served at https://clearlydue.com through GitHub Pages.

- `index.html`: the single-file page (browser edition 1.3.0, design-partner build). Data entered in the demo stays in the visitor's browser.
- `CNAME`: custom domain for GitHub Pages.

Source and build: ClearlyDue product package 1.3.0 (`browser_edition`, `node build.js`, output `dist-partners/index.html`).
